# Spooder-MediaPlayer

A [Spooder](https://github.com/GreySole/Spooder) plugin that plays sounds, images, videos and Twitch clips on an overlay. Fire it from a node in the event editor or over OSC.

## Install

Install it from the Plugin Store in Spooder's Web UI, then add the **media_player** plugin as a layer in your overlay layout.

Put your own files in the plugin's asset folders (`sound`, `image`, `video`); they are not part of this repo.
